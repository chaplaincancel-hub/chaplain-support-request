CHAPLAIN SUPPORT REQUEST - FREE-FIRST PWA

This package is a working phone-friendly Progressive Web App prototype with no paid API, AI service, SMS gateway, or subscription.

IMPORTANT LIMITATION OF THE $0 STATIC VERSION
A static web app cannot silently send an email or text by itself. When a person submits a request, the app prepares the request and opens their normal email application so they can send it. This avoids paid messaging services and avoids placing private credentials inside the app.

The included Chaplain Request Log stores requests only in the browser/device where the form was submitted. It is useful for testing and demonstrations, but it is NOT yet a cross-device cloud dashboard.

TO TEST LOCALLY
Open index.html in a browser. Some PWA install/offline features require serving the folder over HTTPS or localhost rather than opening the file directly.

TO PUBLISH FREE
Upload these files to a free static HTTPS host such as GitHub Pages or Cloudflare Pages. No paid API is required for the app itself.

NOT FOR EMERGENCIES
The app displays an emergency notice directing immediate threats to 911/department procedures.
